# 報告說明

- 寫在report/main.tex
- 照著 @docs/Project04/  作業說明提到的內容寫
- 閱讀者是助教，不要寫助教已經知道的資訊
- 目標不是把所有細節想辦法擠進3頁，而是隱藏瑣碎細節，只寫重要步驟、關鍵細節、成果
- 12 pt 標楷體+times new roman
- 不要刻意把行高壓得很小，當你需要這麼做的時侯應該先檢討哪裡可以寫的更簡單，或刪掉
- 寫作基本要求
  - 對於閱讀者不應該知道的名詞應該先解釋才使用，不然就換個說法加個標註
  - 不要呈現重複資訊(不用摘要、總結)
  - 目的性寫作:每段傳達一個觀點，該段的敘述都是為了該觀點存在，不是的話就不應該出現
  - 因此寫作邏輯應該是想清楚「要傳達哪些觀點(標題)」才決定用哪些敘述支持這個觀點
- 當一個觀點難以傳達，或者用圖可以快速理解，就應該作圖(tikz或其他工具)、或者用圖表等各種方法呈現
- 此為個人作業，第一人稱使用「我」

完成後再次檢查上述幾點，持續修正
